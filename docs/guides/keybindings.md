# ⌨️ lazypackage Keybindings

lazypackage is designed to be completely keyboard-driven, providing a fast and intuitive experience.

## Default Keybindings

| Key       | Function                               |
| :-------- | :------------------------------------- |
| `j` / `k` | Move up/down the list                  |
| `i`       | Install selected package (Install)     |
| `/`       | Search for packages                    |
| `Tab`     | Switch between panels                  |
| `Space`   | Select/Deselect package (Multi-select) |
| `q`       | Quit application                       |

*Note: You can customize these keybindings in your `config.toml` file. Refer to the [Configuration Guide](configuration.md) for more details.*
